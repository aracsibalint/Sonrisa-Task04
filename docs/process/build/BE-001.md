## Reproduce on a clean Windows checkout

Prerequisites: exact SDK 10.0.303 and nuget.org connectivity for first restore. No Docker, SQLite installation or receiver is needed for BE-001. Verified machine also had Microsoft.NETCore.App 10.0.14 and Microsoft.AspNetCore.App 10.0.11; this was not an SDK-only VM test.

```powershell
$env:DOTNET_CLI_TELEMETRY_OPTOUT = '1'
$env:TESTINGPLATFORM_TELEMETRY_OPTOUT = '1'
dotnet --version
dotnet restore Alerts.slnx --locked-mode
dotnet build Alerts.slnx --configuration Release --no-restore
dotnet test --solution Alerts.slnx --configuration Release --no-build --no-restore
dotnet run --project src/Alerts.Api --configuration Release --no-build --no-restore --no-launch-profile
# In another terminal:
Invoke-RestMethod http://127.0.0.1:5080/health/live
```

Expected liveness body: `{"status":"alive"}`. This means process liveness only. Stop with Ctrl+C. A custom local port can be supplied after `--`, e.g. `-- --urls http://127.0.0.1:15080`. Ambient URL/Kestrel configuration that tries to expose nonloopback listeners fails startup. Do not use this host for nonlocal traffic.

For later tasks, approved local SQLite and a separate current-user DPAPI key directory must remain outside the repository on local non-network storage. Neither storage nor key creation/protection is implemented here. No defaults for passwords/secrets were committed. `.gitignore` excludes build/test outputs, local database journals, local config, key directories and certificate material. Lock files are deliberately not ignored.
