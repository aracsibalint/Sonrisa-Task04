## Scoped steps
1. Implement only approved configured source adapters; no user URLs, arbitrary per-rule polls, redirects or linked-article fetches.
2. Parse bounded untrusted responses outside the database gate using canonical safe XML/text and strict decimal/time handling; normalize before matching.
3. Implement durable RSS first-acceptable-response suppression, seen identities, publication cutoff and response-validator advancement per flows. Preserve invalid-item versus whole-response failure distinctions.
4. Capture market scheduled-slot identity before request, validate symbol/window/freshness and accept the first valid observation per slot. Do not replace a committed observation or backfill missed slots.
5. Call BE-006 for eligible new events and coordinate source state under the shared mutation gate. Persist backoff/status/checkpoints without network I/O under gate/transaction.
6. Wire independent in-process poll scheduling with shutdown cancellation, one in-flight request per source and fresh scopes; poll failures cannot stop per-channel delivery workers added by BE-009. Do not impose a single coordinator class beyond the one-deployable architecture.
7. Execute synthetic fault/restart fixtures; after documented live approval, execute actual runtime adapter checks against each approved provider and record provenance/limitations separately. Preserve permission evidence and outstanding gaps.

## Detailed edge-case tests
- RSS baseline A/B suppresses both durably; subsequent A/B/C accepts only eligible C; crash/restart preserves baseline/seen state. Initial failure remains uninitialized; initial 304 without baseline causes canonical unconditional recovery.
- GUID is opaque; empty GUID uses canonical normalized link fallback; no usable identity is rejected; duplicated/edited identity never rematches. Distinct GUIDs sharing an article link follow the approved identity policy, not accidental article-level dedup.
- Missing/invalid/future publication time, pre-baseline resurfaced items, timezone/entity/NFC variants and oversized summaries follow canonical rules. Ignore excluded full-content fields; hostile markup cannot execute or fetch URLs. Reject XML DTD/entities, invalid document and decompression/item-count overflow safely.
- Conditional 304, changed ETag and crash midway through a response cannot advance validators past unprocessed eligible work. Partial previously committed items deduplicate on replay; capacity failure leaves unaccepted identity retryable. Rule create/pause/resume never resets baseline or seen state.
- Market threshold equality/increase/decrease uses original positive decimals and canonical provider window, not previous poll or rounded provider percent. Reject zero/negative/overflow/malformed decimals, symbol/currency mismatch, wrong interval and stale/future observation; never fabricate zero-valued data or reuse stale data as new.
- Same slot retry/concurrency yields one event; changed accepted payload is reported without overwrite/rematch; identical values in a later slot are a new observation. Retry stops at slot expiry, restart skips missed slots and schedule/config changes follow versioned identity rules.
- Timeout, cancellation, HTML-200, redirect, oversized body, 429/Retry-After, blocked access/region, bans and server failures yield bounded durable outcomes. Honor canonical hints/backoff; one failed source does not starve another or delivery. Logs distinguish last fetch from last valid observation and do not leak payloads/secrets.
- Config/API inspection proves ordinary users cannot inject source URLs. Gated live tests show actual normalized RSS/market observations and provenance; absence of a new eligible RSS item after baseline is reported honestly rather than bypassing suppression.
- Exercise configured-host DNS resolving to private/link-local/metadata addresses and proxy/redirect attempts against the approved egress strategy; a one-time string allowlist is not proof of SSRF protection. Both compressed and decompressed streaming bounds apply even with absent or misleading Content-Length.

## Completion criteria
